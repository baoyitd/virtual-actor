# 当前 UI 现状参考包（2026-05-29）

> 项目：`virtual-actor`
> 用途：在新工作方无法直接访问当前服务时，辅助理解现有页面状态
> 定位：`Handoff Only`
> 重要说明：**本文件和附带截图只用于理解现状，不是新设计应沿用的视觉、布局、交互或信息架构基线。**

## 1. 使用方式

请按以下方式使用这份参考包：

1. 把它当作“当前页面现状样本”，帮助理解现在做到了什么、哪里有明显问题。
2. 不要把它当成“下一版从这里继续优化”的设计底稿。
3. 新方案仍应优先回到产品定位、目标用户、关键任务流、PRD/真源设计和业务本质来重做。
4. 如截图与你通过代码或文档理解到的内容不完全一致，以“它反映了一个具体时点的运行态现状”来理解，不要据此反推业务语义。

## 3. 如何理解这些截图

建议重点看以下几类问题：

1. 全局视觉是否足够商务、稳重、统一
2. 导航和页面关系是否足够清晰
3. 表单和字段引导是否仍然偏重、偏技术化
4. 资产市场是否足够像“业务发现入口”
5. 使用台/测试台/看板是否足够支撑非技术用户理解结果和状态

## 4. 不应从截图中继承的内容

以下内容不要因为截图存在就默认保留：

1. 现有布局分栏方式
2. 现有卡片样式和留白节奏
3. 现有按钮位置、按钮命名和操作顺序
4. 现有列表密度、表单层级和结果展示分区
5. 现有资产市场和看板的组织方式

如果你判断这些内容本身就是问题，应直接重做，而不是局部修补。
