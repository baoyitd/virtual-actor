# 05. Current Page Reference

## Purpose

This document explains what the screenshot folder contains.

Use it only to understand the current product state.

Do **not** treat it as a required baseline for the new design.

## Screenshot Folder

See:

```text
screenshots/
```

## Screenshot List

| File | Page | What it helps reveal |
|---|---|---|
| `01-login.png` | login | current brand tone, first impression, login surface |
| `02-role-list.png` | role asset list | current navigation, list density, status visibility, actions |
| `03-role-detail.png` | role detail | detail hierarchy and action exposure |
| `04-role-edit.png` | role create/edit | current form weight, grouping, AI area, knowledge binding placement |
| `05-role-test.png` | test desk | current testing surface and result reading |
| `06-usage-desk.png` | usage desk | current formal usage surface and result reading |
| `07-marketplace.png` | marketplace | current discovery expression, recommendation area, card expression |
| `08-dashboard.png` | dashboard | current operational expression and metric framing |

## How To Use The Screenshots

Recommended use:

1. identify what feels too “backend”
2. identify what feels too weak for enterprise business usage
3. identify what is unclear in navigation and user task progression
4. identify what parts are too form-heavy or too thin

## How Not To Use The Screenshots

Do not assume the redesign should keep:

1. the same layout
2. the same card model
3. the same spacing rhythm
4. the same list structure
5. the same marketplace shape
6. the same dashboard grouping
7. the same create/edit information architecture
