# Virtual Actor UI/UX Redesign Package

This package is prepared for a new design partner who will redesign the product UI/UE/UX.

Use this package as a standalone input. It only includes:

1. product context
2. current scope and hard boundaries
3. core user flows
4. current UI/UX problems and redesign goals
5. expected design deliverables
6. current UI screenshots for reference

Important:

1. The screenshots in `screenshots/` are only for understanding the current state.
2. They are **not** the visual, layout, or interaction baseline for the new design.
3. The new design should primarily respond to the product goals, user scenarios, and business requirements in this package.
