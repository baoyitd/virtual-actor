# v0.4.0 设计增量

> 基线来源：v0.3.0-commercial-trial Accepted
> 用途：记录下一轮相对 v0.3.0 的增量设计

## 1. 背景与目标

v0.3.0 已完成内部商业试用验收。下一轮需要先把产品迭代需求从口头记录转成可验收设计，避免再次出现字段不会填、知识选择不可用、交付证据滞后的问题。

## 2. 关键变化

| 设计项 | 决策 | 影响范围 |
|---|---|---|
| DD-01 | 待确认角色模板库是否进入本轮实现 | 角色创建、配置复用、运营维护 |
| DD-02 | 待确认 AI 辅助填充是否进入本轮实现 | 角色创建、LLM 调用、表单回填 |
| DD-03 | 待确认历史版本详情入口是否进入本轮实现 | 角色详情、版本查看、发布追溯 |
| DD-04 | 待确认详情页枚举中文映射是否进入本轮实现 | UI 文案、用户理解 |

## 3. 数据与状态变化

待需求确认后补充。当前 Draft 阶段不引入 schema、API 或公共契约变化。

## 4. 风险与边界

1. 模板库如果变成可运营资产，需要先明确数据模型和维护边界。
2. AI 辅助填充如果进入实现，需要明确 LLM 失败、部分字段回填和人工确认机制。
3. 若涉及公共契约或决策产品集成，必须先上提裁决。
