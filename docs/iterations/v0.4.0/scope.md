# v0.4.0 范围说明

> 版本：v0.4.0
> Formal Status：Draft
> 最后更新：2026-05-22

## 1. 本轮目标

作为 v0.3.0 Accepted 后的下一轮产品迭代占位版本，先承接已记录的产品需求和体验问题，进入设计澄清阶段；未完成 scope 冻结前不得进入实现。

## 2. Scope In

1. 明确下一轮产品需求优先级和验收路径。
2. 梳理候选需求：角色模板库、AI 辅助填充角色配置、历史版本详情入口、详情页枚举中文映射。
3. 为确认纳入的需求补齐设计增量、测试用例和追溯矩阵。

## 3. Scope Out

1. 未经确认的候选需求不视为本轮承诺交付。
2. 不默认推进决策产品集成。
3. 不改变 v0.3.0 已验收范围和知识平台当前依赖边界。
4. 不新增公共契约、跨项目字段或版本冻结口径。

## 4. 核心场景链

| ID | 场景 | 成功标准 |
|---|---|---|
| US-01 | 需求确认与范围冻结 | 形成明确 Scope In / Scope Out、测试用例和交付标准 |

## 5. 非目标与禁止动作

1. 不在设计未收口时直接编码。
2. 不把候选需求写成已承诺交付。
3. 不用局部页面验证替代最终用户主路径验收。

## 6. 验收标准

1. v0.4.0 scope、design-delta、test cases 和 traceability 完成并一致。
2. 进入实现前明确是否包含角色模板库和 AI 辅助填充。
