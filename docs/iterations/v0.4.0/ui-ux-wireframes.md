## 1. AI 协作创建主流程（DD-10）

### 1.1 场景描述

- 用户：运营方 / 治理方（角色创建者）
- 任务：用自然语言描述需求，AI 生成角色草案，确认后保存为 draft

## 2. 业务输出配置界面（DD-12）

### 2.1 场景描述

- 用户：运营方 / 治理方（角色编辑者）
- 任务：为角色选择/配置业务输出类型和输出结构
- 入口：角色详情页 → [编辑业务输出] 或 AI 创建草案的 Step 3

## 6. v0.4 vs v0.4.x 交互分界标注

| 交互项 | v0.4 必交 | v0.4.x 增强 |
|---|---|---|
| AI 创建意图输入 | ✅ 单文本框 | 多轮对话意图细化 |
| AI 草案展示和编辑 | ✅ 分组展示，逐项编辑 | 拖拽排序、批量编辑 |
| output_type 选择 | ✅ 4 模板卡片选择 | AI 深度推荐理由展示 |
| output_schema 自定义字段 | ❌ v0.4 不支持 | ✅ 自定义字段追加 + AI 推荐字段 |
| 资产市场场景入口 | ✅ 4 场景分类卡片 | 更多场景 + 动态场景组织 |
| 资产市场 AI 推荐 | ✅ 文本输入 + 推荐结果卡片 | 推荐结果对比、排序 |
| 资产市场治理视图 | ❌ v0.4.x | ✅ 筛选、状态管理、质量指标 |
| 资产市场接入视图 | ❌ v0.4.x | ✅ output_type 调用说明、版本信息 |
| 使用台消费输入 | ✅ query + context | 历史查询记录 |
| 使用台结构化结果展示 | ✅ 模板字段逐项展示 | 可折叠/展开、导出 |
| 使用台非 success 状态展示 | ✅ status + reason + boundary | 详细错误恢复建议 |
| 运营看板资产总览 | ✅ 4 数字卡片 | 趋势图表 |
| 运营看板使用运营 | ✅ 使用次数 + 状态分布 | 使用趋势、消费方分析 |
| 运营看板风险运营 | ✅ boundary_blocked + undefined 比率 | 知识过期、边界缺失 |
