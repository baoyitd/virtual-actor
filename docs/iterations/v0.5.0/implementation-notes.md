## 2. 关键落地说明

1. 截至 `2026-06-11`，`v0.5.0` 的代码实现已按冻结口径覆盖角色定义、说明卡、治理发布、外供与追溯的主链路；工作方预检、测试方本地独立复核与代表环境验证均已完成，`Formal Status` 已升级为 `Self-Tested`。
2. `L3` 继续保持“角色页只做绑定、不做自由文本能力说明”的实现方向；数据能力通过平台服务端查询层生效，不把数据库连接暴露给角色页或外部环境。
3. `DD-18` 页面能力与后端状态已闭合：`使用前说明与调用预览` 读取同一张说明卡当前保存版，发布 / 外供与前置查看共享同一份真源文本。
4. 资产市场与推荐链路已共用已发布版本的公开详情结构，不再各自拼接一套角色摘要；推荐池准入继续要求 `published version + business_domain + output_type + applicable_scenarios + 角色摘要`。
5. `Codex` 代表环境已在隔离 fresh session 中闭合：仅复制 `Skill package` 与 provider 配置，不依赖仓库源码，完成一次真实调用并在平台侧落下 `external_skill` 的 `usage_record`。
6. `Dify` 代表环境已在本地真实环境中闭合：基于导出的 `Tool package` 派生 provider 文件完成导入、真实调用，并在平台侧对账 `usage_record / role_version_id / status / boundary_status / sources`。
7. 当前下一步已从“补代表环境验证”转为“进入最终用户测试 / 验收”；`v0.3.0-commercial-trial` 仍保留为唯一 `Accepted` 对外交付基线。
8. 因知识平台 `v1.6` 拓扑重构，角色产品已转为“按 `knowledge_object_id` 路径识别真实知识库 + 默认 Eve 优先”的兼容模式；这属于消费行为兼容修复，不新增角色产品对外接口字段。
