## 追溯使用规则

1. 若需求再次调整 `L3`、`L4` 或页面分层，必须先改 `requirements-analysis.md`，再同步本表。
2. 若出现新增页面或新增对象，但没有明确回指到哪个 `DD` 和哪个 `US`，不得直接进入实现。
3. `US-30` 是为了闭合已确认的“管理员数据资产管理页” requirement，不构成额外 scope 扩张。
4. 若实现阶段又把旧 `capability_*` 写回正文，或把数据能力重新做成自由文本说明，必须先回写 `implementation-notes.md`。
5. 若测试计划或原型与本表不一致，以 `requirements-analysis.md -> design-delta.md -> traceability.md` 顺序重新校准。
